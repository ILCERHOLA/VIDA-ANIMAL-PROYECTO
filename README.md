# 🐾 VIDA-ANIMAL-PROYECTO

Proyecto completo de gestión veterinaria con frontend en React y backend en Node.js + MySQL.

---

## 📁 Estructura del proyecto


---

## 🚀 Tecnologías utilizadas

- **Frontend:** React, JavaScript, HTML, CSS
- **Backend:** Node.js, Express, MySQL
- **Hardware:** ESP32 (ESP-IDF)
- **Herramientas:** dotenv, Visual Studio Code, Git, GitHub, MySQL Workbench

---

## 📦 Requisitos generales

- Node.js v18 o superior
- MySQL instalado y corriendo
- Archivo `.env` con las credenciales de conexión
